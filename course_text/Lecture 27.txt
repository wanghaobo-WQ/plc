Polymorphism using abstraction
In the above code, we created variables of type interface (
Vehicle_Interface
) – vehicle1 &amp; vehicle2. Then we assigned the objects of type car and bus to them - vehicle1=new Car(), vehicle2 = new Bus().
 
This is called polymorphism using abstraction, where a variable of one type can behave like different objects. Look at the program output, and you will notice that the variable of type ‘Vehicle’
 
behaved
 
like
 
an
 
object
 
of
 
type
 
Car
 
and
 
Bus,
 
depending
 
on
 
the
 
type
 
of
 
object
 
assigned to it.
