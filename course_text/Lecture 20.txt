Constructors
We looked at the class methods/functions in the earlier section. Those methods were considered class members and can be invoked (called) whenever you want. However,
Java provides a special type of method to the classes. This method is known as ‘Constructor’.
A
 
‘Constructor’
 
is
 
a
 
special
 
function/method
 
that
 
helps
 
you
 
construct/create
 
an
 
object
 
of
 
that
 
class and initialize its variables. A ‘Constructor’ method is called whenever you try to create an object using the ‘
new
’ keyword. You have used the ‘new’ keyword in earlier examples, so you should know that the ‘new’ keyword is used whenever you want to create an object of any class type. Recall this line of code: 
Student st1 = new Student();
In this line, we are creating a new instance(object) of type Student. When Java executes this line of
 
code,
 
it
 
calls
 
the
 
‘Constructor’
 
method
 
of
 
the
 
‘Student’
 
class
 
to
 
construct
 
the
 
student
 
object
 
and initialize all variables in the student class

EXPLICIT / USER-DEFINED CONSTRUCTOR
As mentioned earlier, a constructor is a special type of method in a class, and how you create a constructor differs from how you create other methods. To declare a constructor, you need to follow the rules given below:
1.	The name of the constructor method should be the same as the name of its class (remember Java is case sensitive)
2.	A constructor does not have a return type (not even void)
An Explicit 
or User-defined constructor 
is the one that is 
coded by the programmer
.

IMPLICIT / DEFAULT CONSTRUCTOR
An Implicit or Default constructor is a method that
 
is not
 
coded by the programmer; rather, it is provided internally by Java if the programmer did not code a constructor. In the examples from earlier chapters, we did not code a constructor method, and even then, the program worked fine, and the class objects were created.
 
The thing is, Java looks for programmer-defined constructors first. If a class does not have a programmer-defined constructor, Java provides a default constructor method to create an object of that class.
