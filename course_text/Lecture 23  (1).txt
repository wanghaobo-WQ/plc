JAVA PACKAGE
A Java package is like a folder. When you develop an application involving multiple classes, you need a way to organize those class files. Java provides the ‘package’ mechanism for you to do that. Using a package, you can 
logically group your class files 
to make your program more readable and relatively easy to maintain.
A package also 
provides access level protection 
to your classes and attributes. As we learned in the ‘Access specifier’ section, the package-private access specifier limits the access of classes and attributes to the classes in the same package.
 
The package mechanism provides one more feature. A package also provides 
individual namespace to classes
. This means you can have classes with the same name in different packages, and they will not conflict with each other.
