Switch statement
In the if…else statement, if you want to validate multiple conditions and branch the control to a different set of code, you will need to use multiple ‘if…else’ statements. Sometimes, this gets messy if you have to use many ‘if…else’ statements. One of the best practices in writing code is to keep it clean and readable. The ‘switch’ statement helps evaluate multiple conditions and keep the code clean.
 
Syntax:
 
switch
 
statement
Switch
 
(variable)
 
{

                      break;

of
 
statements&gt;
