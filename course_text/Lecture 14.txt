When

For example, if you are creating a variable ‘pi’ and assign a value of ‘3.14159’ to it, then you do not want the value of this variable to change because ‘pi’ is a mathematical constant. Its value is always ‘3.14159’ (this number's decimal portion is never-ending).
Another example can be a variable that stores the total number of months in a year, and its value is always 12.

FINAL KEYWORD WITH METHODS
If a class method is declared ‘final’, it cannot be overridden by its child class.
I know you have yet to learn about the ‘classes’, but for now, just remember this: The ‘final’ keyword can be used with Variables, Classes, and Methods. You will learn about using the ‘final’ keyword with Java classes and 
methods later.
