EXCEPTION HANDLING
In
 
Java,
 
handling
 
an
 
exception
 
does
 
not
 
mean
 
preventing
 
it
 
from
 
occurring;
 
it
 
only
 
means
 
that you write a piece of code to take some logical action when that exception occurs so that your program does not end abruptly.
To handle an exception, you need to understand how an exception works. Whenever Java encounters a situation similar to the ones given in our Checked and Unchecked exception examples, Java 
throws 
an exception. All we have to do is to ‘
catch
’ that exception and then execute logical steps based on the exception.

=== ppt/slides/slide15.xml ===
finally Block
The ‘finally’ block is part of Java's exception-handling mechanism. Although it is not mandatory to use it, it provides additional options during exception handling.
The ‘finally’ block is added after the ‘catch’ block. The code given in the ‘finally’ block is executed after the try…catch block execution is complete. When Java executes the code given in the ‘try’ block, regardless of whether there is an exception or not, the ‘finally’ block code is always executed. You can use the ‘finally’ block to write any clean-up code you want to execute at the end of your try{} block code. Here’s the syntax of the ‘finally’ block with the try…catch block.
Syntax:
 
‘finally’
 block
try 
{
&lt;Primary
 
code for
 
execution&gt;
}
catch(Exception
 
e)
 
{
&lt;Code
 
to
 
be
 
executed when
 
an
 
exception
 
is 
caught&gt;
}
finally{
&lt;Code
 
to
 
be executed
 
after executing
 
the try{}
 
block, whether
 
an exception
 
or 
not.&gt;
}
