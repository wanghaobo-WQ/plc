‘OBJECT ORIENTED PROGRAMMING’ USING JAVA
Now that we understand what an object is and that every object has properties/attributes and behaviors, the next question is – How is Object-oriented programming implemented in Java?
 
Let us recall what we learned about ‘Arrays’ - an Array is a 
data structure 
that can hold multiple values of the 
same type
.
To implement object-oriented programming, Java provides another type of data structure called – ‘
Class
’. A ‘Class’ is another type of data structure that allows you to store 
multiple values of different types
. It also allows you to create a logical group of related data items. From a ‘Class’, you can create multiple instances of that type, known as ‘Objects’. You will learn about ‘Classes’ and ‘Objects’ in upcoming sections. For now, it is important that you familiarize yourself with the concept.
