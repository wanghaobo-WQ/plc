Working with Arrays in Java
When you start writing programs, you will come across situations where you may want a single variable to hold multiple values at the same time.
Variable Types

All these types of variables can hold only ONE value at a time.
You can use ‘Arrays’ to store more than one

ARRAYS
There are multiple ways to declare an Array variable. But first, you need to know one thing about arrays – The length of an Array cannot be changed once it is declared.
This means
 
that if I declare an Array of size 5 (so that it can hold five different values), then the size of that array variable will always remain 5, and you cannot change it.
