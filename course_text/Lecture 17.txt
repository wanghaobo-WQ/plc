JAVA METHODS WITH PARAMETERS
Like our mathematical function f(x), Java methods can also accept parameters. If you want to pass certain data to your method, then you need to define the method with parameters.
Earlier, we wrote a method to print the sum of two numbers, and both numbers were defined in the printSum() method. This time, we will pass these numbers as parameters to the printSum() method.
