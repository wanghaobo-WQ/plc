## 1. 电压、电流、功率

水管类比：

| 电气量 | 符号 | 单位 | 类比 |
|---|---|---|---|
| 电压 | U/V | 伏特 V | 水压（推力） |
| 电流 | I | 安培 A | 水流量 |
| 电阻 | R | 欧姆 Ω | 水管粗细/堵塞 |
| 功率 | P | 瓦特 W | 干活快慢 |

- 核心公式：**P = U × I**（例：220V × 5A = 1100W）
- 电压是原因，电流是结果；没有电压差就没有电流
- 安全：36V 以下基本安全；控制回路常用 24V，动力回路用 220V/380V

## 2. DC 直流 vs AC 交流

| | DC 直流 | AC 交流 |
|---|---|---|
| 方向 | 不变 | 周期变化（中国 50Hz） |
| 来源 | 电池、开关电源 | 电网、墙壁插座 |
| 常见电压 | 5V/12V/**24V** | **220V**(单相)/**380V**(三相) |
| 符号 | ⎓ | ～ |

PLC 系统分工：
- **AC 走动力**：电机、加热器等大功率设备
- **DC 走控制**：PLC、传感器、按钮、线圈，标准 24V
- 桥梁：继电器/接触器（弱电控强电）

接线标识：
- L/N = 交流火线/零线；L1 L2 L3 = 三相火线；PE = 保护地
- +24V / 0V(或M) = 直流正/负极
- VAC = 交流；VDC = 直流（课件 120 VAC = 交流120V，美式，中国对应220V）

## 3. 继电器 Relay 与接触器 Contactor

原理相同：**电磁开关**——线圈通电吸合触点，断电弹簧弹开。用小电流（24V安全）控制大电流（380V危险）。

一个线圈的两种触点：

| 触点 | 线圈断电时 | 线圈得电时 | 符号 |
|---|---|---|---|
| 常开 NO | 断开 | 闭合 | ─┤ ├─ |
| 常闭 NC | 闭合 | 断开 | ─┤/├─ |

- 启动按钮、自锁触点 = 常开；停止按钮、热保护 = 常闭
- **继电器**：小功率，柜内信号/逻辑传递
- **接触器**：大功率，直接通断电机，带灭弧罩。课件里的 **M（Motor starter coil）** 就是接触器：主触点带电机，辅助常开触点做自锁
- **热继电器 OL**：检测电机长期过流发热，跳开常闭触点，串在控制回路里做过载保护
- PLC 出现前，继电器接线实现逻辑：串联=AND、并联=OR、常闭=NOT、自锁=记忆；改逻辑要重新接线 → PLC 用软件代替硬接线（hardwired → programmed）
- 现代标准链路：PLC输出点 → 接触器线圈 → 主触点 → 电机

## 4. 传感器（PLC 的五官）

开关量传感器：

| 传感器 | 原理 | 用途 |
|---|---|---|
| 光电 Photoelectric | 光被挡/反射 | 计数、检测物体到位 |
| 接近 Proximity | 电感（金属）/电容（非金属）感应 | 位置检测、门是否关严 |
| 限位 Limit | 机械式碰撞 | 运动终点硬保护（电梯、传送带） |
| 压力 Pressure | 压力到设定值动作 | 罐体压力联锁 |
| 温度 Temperature | 温度超限动作 | 温度联锁 |
| 急停 E-stop | 红色常闭按钮 | 一按全停 |

- 输出类型：**PNP**（输出+24V，中/欧常用）vs **NPN**（输出0V，日系常用），接线前必须确认
- **开关量**：只有0/1（DI/DO）；**模拟量**：连续值 4-20mA / 0-10V（AI/AO，如实际温度/液位）

## 5. 完整信号链（全课总结）

```
物理量 → 传感器(24VDC，通/断) → PLC的DI输入(1/0，进I/O映像区)
       → PLC程序(梯形图逻辑) → DO输出24V → 接触器线圈
       → 主触点闭合 → 380VAC电机
```
传感器"感知"，PLC"思考"，接触器"动手"。

## 6. 梯形图 ↔ 布尔表达式（重点，结合 L15 slide30）

铁律：
- **"·" = 与 = 串联**（都满足才行）；**"+" = 或 = 并联**（一个满足即可）
- 停止/保护类常闭开关一律串联在干路
- 表达式右边出现输出自己（M/Y）= 自锁（seal-in/latching）触点
- 分析时序按 PLC 扫描逐拍代数字；自锁触点取**上一拍**的输出值

课件例题（双启停）：

```
M = (A + B + M) · C · D
Y = M̅  （NOT门，停止指示灯）
```

起保停通用公式：

```
输出 = (启动信号 OR 输出自身) AND (所有停止/联锁条件)
```

练习记录：
- 第1题（双启动+停止+热保护）M=(S1+S2+M)·ST·OL ✅ 正确
- 易错点：题目说"A和B都按下"要用 A·B（串联），不是 A+B。口诀：**和点或加**

## 7. 三相电与星三角接法（2026-10-11 补，第2周内容）

- 单相（L+N）供家用小功率；三相（L1/L2/L3）供工厂电机，转动平稳力矩大
- **电压口诀：相间 380，相对零 220**（线电压=相电压×√3，380≈220×1.732）
  - L1↔L2、L2↔L3、L3↔L1 = 380V；任一 L↔N = 220V
- 电机内部 3 组绕组 6 个头（U1/U2、V1/V2、W1/W2），两种接法：

| 接法 | 接线 | 每相电压 | 特点 |
|---|---|---|---|
| 星形 Y | 尾端 U2/V2/W2 短接，头接 L1/L2/L3 | 220V | 启动电流小、力矩小 |
| 三角形 △ | 首尾相连成环，3点接 L1/L2/L3 | 380V | 满功率、力矩大 |

- **星-三角降压启动**：大电机直接△启动电流达额定5-7倍 → 先Y启动（电流约1/3）→ 几秒后靠**时间继电器(TON)** 自动切△运行
- 铭牌：`3~ 380V 50Hz`=三相380伏50Hz；新西兰工业电 400V三相/230V单相 50Hz，与中国同电压等级

## 8. PLC 扫描周期（2026-10-11 CoDeSys 实测）

三步循环：**读输入 → 执行程序 → 写输出**

- 本机 MainTask 配置：类型=循环(Cyclic)，周期=**20ms** → 每秒扫描 50 次
- 实测方法：PLC_PRG 中 `nScanCount : INT;`，代码 `nScanCount := nScanCount + 1;`，在线监视数字每10秒涨约500
- INT 上限 32767，约11分钟溢出归零 → 工业计数应用 DINT（上限约21亿）
- F5 停止=计数冻结，再启动=继续累加；工程意义：看计数器涨不涨可判断PLC是否在执行程序

## 9. CoDeSys 操作速查（第1-2周实操）

完整流程：新建 Standard project（设备 Control Win V3 x64 + 语言 LD）→ 画梯形图 → F11 编译 → 在线→仿真→登录(Alt+F8)→下载→F5 启动 → 在线监控

| 快捷键 | 作用 |
|---|---|
| F11 | 编译 |
| Alt+F8 | 登录/退出登录 |
| F5 | 启动/停止 PLC |
| F7 | 强制值（锁住，每扫描周期保持，变量标红F） |
| Ctrl+F7 | 写入值（只写一次，程序可覆盖） |
| Shift+F7 | 解除强制 |

ST 语法注意：
- 注释必须半角：`(* ... *)` 或 `// ...`，中文括号（）会报错
- 赋值符 `:=` 必须紧挨无空格，半角冒号；语句以半角 `;` 结尾
- 无参调用程序：`LD_Main;`（本版本也接受 `LD_Main();`），但必须写在代码区（END_VAR 下方），不能写进声明区
